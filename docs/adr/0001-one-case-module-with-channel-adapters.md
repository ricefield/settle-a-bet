# One Case module with channel adapters

The web-originated and X-assisted experiences will call one deep Case module through a channel-neutral interface. Web, X, and administration are adapters at that seam; they may translate channel input and present channel output, but they do not own framing, participation, locking, moderation, evaluation, or publication rules. This avoids two subtly different Case implementations while allowing either initiation path to be built first.
